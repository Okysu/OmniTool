# 测试场景覆盖 · 第 3 轮

> 面向：本项目的开发者与评审者。

## 运行

```bash
pnpm test          # 单元测试（vitest，230 个，约 0.6 秒）
pnpm test:e2e      # 端到端（Chromium）：生成素材 → 构建 → 预览服务 → 5 个套件
OMNITOOL_E2E_OFFLINE=1 pnpm test:e2e   # 跳过需要下载模型的 ai 套件
```

素材由 `e2e/fixtures.mjs` 生成：PNG、PDF（纯文字 / 含图片与空白页 / 修订版）、测试视频（有音轨、不同分辨率无音轨）、
AAC 音频、10 帧 GIF、TIFF、带目录的 ZIP，以及由 Chromium 渲染的 OCR 文字图与抠图用对象图。
视频与动图由**系统 ffmpeg** 生成——浏览器内的 FFmpeg 是被测对象，不能自己造素材。

## 端到端（81）

### smoke（14）
沿用：跨源隔离、沙盒隔离层级、OPFS、越权探针（CSP 拦截直连网络、IndexedDB 不可达、未授权能力被拒绝）等。

### tools（40）
在真实浏览器里逐个运行工具。本轮新增：
- **ImageMagick 在沙盒 Worker 中按需加载**并读出 GIF 全部 10 帧；拆帧；缩放后仍为 GIF；TIFF 经 magick 解码、Canvas 编码。
- **归档**：创建 ZIP；解压保留 `docs/图片/说明.md` 这样的中文目录。
- **PDF**：含图片页面的渲染（回归用例）、删除空白页（只删真正的空白页）、提取嵌入图片、按最大字号标题重命名、文本比较并在渲染预览中读出高亮的新增内容、清理、小册子。
- **音视频面板**：在时间轴上点击定位并标记两帧后导出；按间隔抽帧；用上移按钮调整顺序后拼接不同分辨率且无音轨的片段；纯音频拼接；开启裁切、选 1:1、旋转 90° 后面板显示 `240 × 240` 并导出；拖动淡入滑块后校验包络曲线从 0 升到 100%。
- 等待条件改为 `data-task-status` 属性：失败立即返回错误信息，而不是等到超时。

### ui（12）
新增：粘贴 `02-plugin-api.md` 全文转 HTML，**渲染预览中的标题数与源文件一致**，末尾段落存在；预览中的外部图片请求被 CSP 拦截；源码标签显示完整文档。

### editor（8）
沿用。

### ai（7）
- OCR：两次模型下载确认 → 下载 → SHA-256 校验 → 识别出「本地离线识别OCR2026」与「Hello, OmniTool!」。
- 抠图：输出中约 79% 像素透明，主体中心不透明。
- 放大：160×120 → 320×240。
- 无页面错误。
