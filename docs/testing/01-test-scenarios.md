# 测试场景覆盖 · 第 1 轮

> 面向：本项目的开发者与评审者。

## 1. 自动化端到端套件

```bash
pnpm test:e2e
```

该命令会生成测试素材、构建产物、拉起带 COOP/COEP 头的 `vite preview`，
用 Chromium 跑完整套检查，再关掉服务。

素材由 `e2e/fixtures.mjs` 现场生成，不入库：
一张 512×512 的真实 PNG（657 KB），以及两个分别 2 页与 3 页的真实 PDF。

### 覆盖项（14 项，均通过）

| # | 场景 | 断言 | 实测结果 |
| --- | --- | --- | --- |
| 1 | 跨源隔离 | `crossOriginIsolated === true` | ✅ 已启用，SharedArrayBuffer 可用 |
| 2 | 内置插件注册 | 两个内置插件启动沙盒并注册出 ≥3 个工具 | ✅ PDF 合并 / PDF 提取页面 / 批量压缩 |
| 3 | 沙盒隔离层级 | 达成 `iframe-worker` 而非降级层 | ✅ 独立源 + Worker |
| 4 | VFS 存储层 | OPFS 探测成功而非退回内存 | ✅ OPFS 持久化 |
| 5 | 图片插件端到端 | 拖入 PNG → 运行 → 产出结果 | ✅ 657.6 KB → 6.0 KB（-99.1%） |
| 6 | 输出格式正确 | 产物为 `.webp` | ✅ sample.webp |
| 7 | iframe 不可达 | `sandbox="allow-scripts"` 且宿主拿不到 `contentDocument` | ✅ `reachable: false` |
| 8 | UI 线程响应性 | 处理期间到下一帧 < 250ms | ✅ 9–12ms |
| 9 | 依赖注入 + PDF 合并 | pdf-lib 被注入，2 个文件合成 5 页 | ✅ 已合并 2 个文件，共 5 页 |
| 10 | 安装审查完整性 | 弹窗只列出清单声明的能力 | ✅ 仅「文件读写」，无「网络请求」 |
| 11 | 沙盒内直连网络被拦 | 插件内 `fetch()` 抛错 | ✅ `fetch:BLOCKED` |
| 12 | 未授权 `host.net` 被拒 | 宿主拒绝未授权能力 | ✅ `host.net:DENIED` |
| 13 | 未授权 `host.kv` 被拒 | 同上 | ✅ `host.kv:DENIED` |

场景 11–13 由一个故意越权的探针插件驱动：它只申请 `fs`，
却尝试 `fetch`、`indexedDB`、`host.net.fetch`、`host.kv.set`，
把每项结果写进一个文本文件再返回。副产物 `idb:BLOCKED` 顺带证实了
IndexedDB 在不透明来源下确实不可达——这是 `allow-same-origin` 缺席的直接后果。

## 3. 已知未覆盖

诚实记录，避免在第 2 轮重复踩：

- **仅在 Chromium 上验证过。** Firefox 与 WebKit 的浏览器包在本机可用，但套件尚未接入。
  两者最可能出现差异的点：不透明来源下的 blob Worker（可能降级到 `iframe` 层）、
  OPFS `createWritable`（Safari 主线程不支持，应退回内存模式）、AVIF 编码支持。
- **`ffmpeg.*` 未实现**，因此没有真实的音视频转码路径可测。
- **远程订阅**的解析与"不得自我提权"更新策略已实现，但端到端测试只覆盖了本地粘贴安装。
  需要一个测试用的 HTTP 端点才能完整验证。
- **大文件压力测试未做。** 架构上（句柄式 VFS + OPFS 流式写入）应当支持 GB 级文件，
  但尚无实测数据。
- **依赖 `integrity` 校验**的正例与反例均未自动化测试。
- **无单元测试。** 纯函数层（`lib/zip.ts` 的 CRC32 与 ZIP64 分支、
  `plugin/analyze.ts` 的模式匹配、pdf-tools 的 `parseRanges`）值得补一组，
  它们的边界条件靠端到端很难覆盖到。

## 4. 回归基线

下列数值来自本机 Chromium，供后续比对：

- 冷启动到内置插件注册完毕：约 1.5s（含两次一次性的沙盒探针启动）
- 512×512 PNG → WebP q80：41ms
- 5 页 PDF 合并（含 pdf-lib 注入）：首次约 250ms，依赖缓存命中后更快
- 生产构建产物：主 chunk 249 KB（gzip 87 KB），CSS 42 KB（gzip 8 KB）
