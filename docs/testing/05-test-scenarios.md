## 手工 / 截图核对

- 悬浮任务队列：1280 宽桌面下胶囊与展开列表；拖动后位置；390 宽手机视口下窗口缩放后自动回到可视区。
- 设置 → 本地模型：下载源选择、镜像地址说明、模型列表空状态。
- 流程图：1920×1080 下运行「图片发布」模板两张图片，节点状态、连线文件数、检查器滚动、75% 适应缩放。
- 教程：独立页面布局、第 2 课自动运行结果；**从工作流页面内跳转进入教程**（发现并修复了进入时预览不运行的问题）。
- 标识：16 / 32 / 48 / 64 px 与深色背景下的可读性。
- Markdown：用 `e2e/test.md` 在上传与粘贴、内联预览、预览对话框、Markdown 转 PDF（逐页渲染核对 14 页）、`vite preview` 与 `pnpm dev` 下验证完整输出。
