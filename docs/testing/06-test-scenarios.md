## 本轮新增

### 测试夹具

`tests/harness/plugin.ts` 增加了 `host.net` 与 `host.secret` 的模拟，规则与宿主一致：

- `secret.request` 对已存在的凭据立即返回（除非 `force`），否则由测试脚本扮演用户输入或取消，并记录每次弹窗的参数。
- 请求中的 `{{secret:name}}` 只在凭据存在且目标 origin 在允许列表中时替换，否则请求失败。测试断言看到的是替换后的请求，与模型服务实际收到的一致。
- `run(..., { fetch })` 扮演网络；未提供时请求以「Failed to fetch」失败。每次请求记录在 `result.requests` 中。
