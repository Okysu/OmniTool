## 二、过程中发现并修复的问题

1. **教程从应用内跳转进入时预览不运行**。进入页面时立即执行的监听器用到了在它之后才声明的变量；刷新直接打开时插件注册表尚未就绪、监听器提前返回，恰好掩盖了问题。
2. **教程代码可能冒用已安装插件的 id**。存储、推理会话与文件都按插件 id 归属，冒用会读到那个插件的 `kv`。现在直接拒绝加载。
3. **教程里代码加载失败时仍显示上一次的运行结果**，看起来像是新代码产生的。加载失败时清空。
4. **流程图第一版在大屏上文字过小**（为了放下全部节点缩到 58%）且画布被检查器撑到 900 px 高。改为固定画布高度、适应时不小于 75%，更长的流程靠平移。
5. 模型 id 作为缓存文件名，增加了字符限制，避免与新增的元数据文件冲突。
