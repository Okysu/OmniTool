> 面向：项目负责人。回答「这一轮做了什么、为什么这样做、还剩什么」。

本轮的输入：

1. 按主流开源项目的标准补齐 Markdown 文档、CHANGELOG 与开源协议（选定 MIT）。
2. 推送到 GitHub。
3. 在仓库中做一批与大模型相关的扩展，例如 AI 翻译、利用归一化坐标的 VLM 目标检测打标，越多越好。它们需要联网或本机 Ollama，因此不随程序本体分发、不内置，由维护者通过 jsDelivr 提供订阅；接口兼容 OpenAI，API Key 使用 `secret` 能力保管。

## 二、关键决策

1. **一个插件而不是一组插件**。连接设置（`kv`）与 Key（`secret`）都按插件 id 隔离，拆开后每个工具都要重新配置、重新录入 Key。
2. **Key 绑定接口的 origin**。插件只在请求头里写 `{{secret:apiKey}}`，由宿主替换，且仅限录入时指定的域名。更换服务商后工具会主动请求重新录入，而不是让请求在宿主处失败。
3. **服务商差异在插件里消化，不要求用户理解**。不支持 JSON 模式时自动去掉 `response_format` 重试；429 / 5xx 按 `Retry-After` 退避；剥离推理模型的 `<think>`；从代码块或说明文字中提取 JSON。
4. **翻译保证格式不被模型破坏**。Markdown 的代码块不发给模型；字幕按条以 JSON 数组往返，条数对不上就逐条重译，避免时间轴错位；i18n JSON 只提取字符串值，键和结构不经过模型。
5. **目标检测只用一种内部表示**。提示词要求 0–1000 归一化坐标；解析端识别 Gemini 的 `box_2d`、0–1 小数与 Qwen2.5-VL 的绝对像素（相对于发送的缩放图），统一落到 0–1 后再导出 YOLO（归一化）与 COCO / LabelMe（原图像素）。
6. **本机模型不开后门**。Ollama / LM Studio 仍受「插件访问本机与内网」开关约束；README 写清了开关与模型服务端的跨域设置，错误信息也会提示。

## 三、过程中发现并修复的问题

1. **通过导入或订阅安装的插件，刷新后消失**（既有缺陷，影响所有非内置插件）。审查对话框把候选插件放在 `ref` 中，`commitInstall` 拿到的是响应式代理，IndexedDB 无法克隆；`persist()` 吞掉了异常。现在先 `toRaw`，写入纯 JSON 快照，失败时提示。内置插件每次启动重新登记，所以之前的测试一直没有覆盖到。
2. **批量请求使用凭据时提示刷屏**。每个请求一条提示，一次翻译就是几十条。改为同一插件、同一域名、同一组凭据在 15 秒内合并为一条，并显示次数。每次使用仍被提示与记账。
3. **安装审查误报「直接网络调用（将被拦截）」**：规则把 `host.net.fetch(` 也当成了裸 `fetch(`，所有正确使用宿主代理的插件都会被误报。
4. **安装审查把 `secret`、`onnx` 判为「声明了但未使用」**：能力使用检测里缺这两项。
5. **对话框内容溢出**（本轮反馈）：见上表，修在 `DialogContent` / `DialogScrollContent` 组件。
6. **拖放区的「接受的格式」在窄栏里不换行**，溢出到容器外。工作流运行栏变窄后暴露出来；居中的弹性子项保持单行宽度，已限制最大宽度并允许任意位置断行。
7. **侧边栏置顶项拖动排序可能移动错误条目**：按显示列表的下标修改设置，当存在已失效的置顶项（插件已卸载）时两者错位。改为按键移动。
8. 扩展开发中的问题：`definePlugin({...})` 的参数在求值时就用到了文件末尾才声明的常量（暂时性死区），已把这些常量移到文件开头；检测工具使用的图标名 `scan` 不在图标表中，改为 `crop`。

## 四、架构层面

- **Plugin API 没有变化**，扩展只使用公开能力。
- **沙盒安全架构没有变化**。审查对话框的默认勾选策略保持不变：`secret` 为中风险能力，仍需用户手动开启。本轮修改的是风险报告的说明文字、凭据提示的展示方式与插件记录的持久化，均不涉及隔离边界与授权判定。
- 细节见架构文档第 15 节。

## 五、需要你决定的事项

- **卸载插件时不会清除它保存的凭据与 `kv` 数据**。重新安装同 id 的插件（包括同 id 的另一份代码）即可继续使用之前录入的 Key。是否在卸载时一并清除（或询问），属于凭据生命周期的安全决策，本轮没有改动。扩展 README 已提示用户先删 Key 再卸载。
- 订阅地址目前指向 `@main`。建议发布 0.6.0 时打标签，README 中改为固定标签地址，避免 jsDelivr 缓存导致用户拿到不同步的版本。
