# 第 3 轮迭代总结

> 面向：项目负责人。回答「这一轮做了什么、为什么这样做、还剩什么」。

本轮的输入是上一轮验收时提出的一组问题：直接输入框太矮、Markdown 转 HTML 只转了一半、音视频编辑仍是抽象表单、
移动端侧边栏与顶栏不自适应、命令面板太小且不显示动态工具，以及「还没做的也完整做完」。

## 一、本轮的关键判断

| 事项 | 做法 | 理由 |
| --- | --- | --- |
| Markdown 只转一半 | 换成 markdown-it（CommonMark + GFM），YAML / CSV / XML 也换成规范完备的库 | 手写子集解析器的问题不是 bug 能修完的，是覆盖面不够 |
| 音视频可视化编辑 | 新增宿主组件 `media`：播放、波形、选区、**画面上拖框裁切**、旋转调色实时预览、音量包络与试听 | 沿用上一轮确认的「声明式组件树」，插件只描述状态键，像素与音频由宿主处理 |
| magick-wasm 放在哪 | 作为插件的**按需依赖**跑在沙盒 Worker 里，而不是新宿主能力 | 图片插件本来就在沙盒里做像素计算；不新增宿主攻击面 |
| AI 模型选型 | U²-Netp / IS-Net / PP-OCRv4 / Swin2SR，全部 Apache-2.0 或 MIT | RMBG-1.4 非商用、APISR 为 GPL，许可比效果更先排除 |
| 空白页判定 | 「无文字层**且**墨迹低于阈值」才删 | 仅按墨迹判断时，只写了一个词的页面会被当作空白删除——宁可漏删不能误删 |

以上均为非破坏性的 Plugin API 新增，沙盒安全架构未改变（`lazy` 依赖的加载范围取自安装记录，见架构文档 11.1）。

### 2. 界面

- 直接输入框加高（约 20 行，可拖拽）。
- 文本结果：显示行数与字节；HTML 结果默认**渲染预览**（沙盒 iframe + 禁止一切网络的 CSP），可切换源码、展开。
- 文件预览：HTML 同样渲染预览；JSON / YAML / XML / CSV / SRT 等按文本预览。
- 移动端：侧边栏改为抽屉，顶栏搜索框折叠为图标，图标按钮收进溢出菜单。
- 命令面板：加宽加高；无查询时按置顶、最近使用、各分类列出**全部已注册工具**（含第三方插件），有查询时按子序列匹配打分排序。

## 三、过程中定位并修复的问题

测试先行暴露了一批「看起来能用、实际有坑」的问题，按影响排序：

1. **含图片的 PDF 页面在沙盒里渲染失败**（已存在于上一轮的「转图片」「压缩」）。pdf.js 默认用 `document.createElement` 创建临时画布，Worker 里没有 `document`。
   此前的测试 PDF 恰好都是纯文字。修复：注入 OffscreenCanvas 画布工厂。
2. **ONNX 推理从未在浏览器里真正跑通**。ORT 的代理 Worker 加载了整个应用 chunk 而崩溃（详见架构文档 11.3）。改为自有推理 Worker。
3. **数据工具的依赖在沙盒里根本没有加载**。严格模式 eval 的顶层 `var` 不是全局变量；单元测试用 `runInThisContext` 恰好掩盖了它。
4. **运行时拒绝 `secret`、`onnx` 能力和 `archive` 分类**：沙盒内的校验列表没随宿主更新。新增同步测试。
5. **插件面板同一 tick 两次变更互相覆盖**（媒体信息被选区覆盖），导致输出尺寸不显示。
6. **拼接视频**：concat 滤镜要求分辨率、SAR、音轨一致，原实现遇到真实用户文件必然失败。
7. **YAML 合并键 `<<: *anchor` 未展开**（docker-compose / k8s 常用）；**JSON 错误行列号**在新版 V8 下丢失（报错信息不再带 position）。
8. **pdf-lib 扁平化表单后留下失效的注释引用**；**空白页（无内容流）无法嵌入**，小册子与长页拼接遇到空白页即失败。
9. **TAR 的 PAX 记录按字节计长**，按字符切片导致所有非 ASCII 路径读错。
10. **APNG 无法编码**：ImageMagick 的 APNG 写出依赖外部 ffmpeg 程序。改为不提供 APNG 输出，并对 APNG 输入明确提示。
11. 同源依赖被永久缓存进 IndexedDB，应用更新后仍加载旧版本。
